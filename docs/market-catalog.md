# 銘柄検索と価格取得

2026-11-03の名簿は7,108件です。東証の株式・ETF・REIT等4,440件、投資信託2,652件、指数・為替・主要な米国株/ETFの16件を収録しています。SBI証券の取扱商品全件との照合はしていません。非NISA投信、外国籍投信、海外の全銘柄などを網羅する名簿ではありません。

## 名簿の出典

- [JPX 東証上場銘柄一覧](https://www.jpx.co.jp/markets/statistics-equities/misc/01.html) の公開Excel。取得時点では2026年9月末の一覧です。
- [資産運用業協会 NISA成長投資枠対象商品](https://www.imaj.or.jp/find/nisa_growth_productslist/index.html) の一般投資家向け・非上場ファンドの公開Excel。2026-10-30更新の一覧を取得しています。
- [三菱UFJアセットマネジメント ファンド検索](https://www.am.mufg.jp/fund/) の公式サイト用検索データ。名称・愛称・読み・協会コード・ISINと運用会社のファンド番号を対応づけています。償還済み商品を除き、上場ETFは取引所の価格側に分けます。オルカンや雪だるまなどの主要な通称も補っています。

同じ投信は投信協会コードで統合します。Excelのふりがなを正式名称へ混入させず、全角・半角を正規化しています。名簿はアプリに同梱しており、検索に通信は不要です。名簿はリリース時に更新します。開発者は `python tools/update-catalog.py` で公式の公開データから作り直せます。自動取得を禁じる投信総合検索ライブラリーのスクレイピングは行いません。

## 検索と登録

名前・愛称・証券コード・投信協会コード・収録済みISINを同じ欄で検索します。ひらがな/カタカナ、全角/半角、英字の大小、空白や記号の違いを吸収し、スペース区切りは絞り込みになります。コードの完全一致を先に表示します。愛称は公式情報と補足した通称の範囲で検索できます。

名簿にない米国ティッカーは英数字・ピリオド・ハイフン、先頭英字で最大6文字の入力を「米国コード（未照合）」として提示します。存在・配信の確認は「確認」で行います。存在を確認できないコードを、推測で投信へ対応づけることはありません。

登録は重複を防ぎ、並べ替え・削除・0件の状態に対応しています。登録と順序、取得確認の日時は、このPCの `%LOCALAPPDATA%\OrbitCalendar\watchlist.json` に保存します。旧版から更新しても初期値は日経平均・ドル円の2件です。いったん設定した登録内容を更新のたびに初期化することはありません。保存できない場合は設定内に案内します。

## 価格取得の状態

| 表示 | 意味 |
| --- | --- |
| 価格取得対応・未確認 | 取得先に接続する実装があります。その銘柄の実データ取得はまだ成功確認していません。 |
| 取得確認済＋日時 | 実際に2件以上の日足/基準価額を読み込めました。確認日時はこのPCの時刻です。常時配信や将来の取得成功を保証する表示ではありません。 |
| 価格取得未対応 | 検索・登録はできますが、その運用会社の価格取得を実装していません。グラフを表示せず、その旨を案内します。 |

Yahoo Financeのチャート配信で指数・為替・株式・ETF等を取得します。対応経路は4,456件ですが、配信対象外や遅延、通信制限があります。日経平均とS&P 500はpt、ドル円は円/ドル、国内株は円、米国株/ETFはUSDを表示します。

投信は三菱UFJアセットマネジメントの公式CSVに対応し、名簿内511件に取得先を設定しています。基準価額（1万口あたり・円）を折れ線で表示します。残り2,141件の投信は価格取得未対応です。たとえばSBI・V・S&P500は検索・登録できますが、今回の版では価格取得未対応です。全511件を個別に疎通確認したという意味ではなく、「確認」で各商品の状態を確認できます。

未対応と通信失敗は区別します。対応銘柄の通信失敗時には再試行を案内し、同じ銘柄の前回データがある場合は日時を添えて残します。別の銘柄のグラフを代用することはありません。

## 検証

`powershell -NoProfile -STA -ExecutionPolicy Bypass -File tools/verify-market.ps1` で、検索の正規化・コード優先・初期値・追加/重複/並べ替え/削除・再読込・0件・価格未対応を確認します。日経平均・ドル円・トヨタ・オルカン・eMAXIS Slim米国株式の実データも取得して画面表示を確認します。テスト用の登録ファイルは一時フォルダーに隔離し、通常の登録内容と基準地点の保存ファイルには書き込みません。
